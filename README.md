# Odoo 18 — Custom MyAddons

Кастомные модули Odoo 18.

## Установка (локально/сервер)
1. Скопируйте каталог `myaddons` в путь, который указан в `odoo.conf` в `addons_path`.
2. Перезапустите Odoo и обновите список модулей.
3. Установите нужные модули через Приложения.

## Правила
- Не коммитим секреты и пароли (используем .env / переменные окружения).
- Не добавляем `venv`, логи, бинарники (см. .gitignore).
- Один модуль — одна папка с `__manifest__.py`.

## Полезно
- Ветка по умолчанию: `main`.
- PR/ревью приветствуются.
